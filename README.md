# MarkDown Auto Preview

打开 Markdown 文件时，自动在右侧打开实时预览；切换到其他文件或标签页时，自动关闭预览。

## 功能

- **自动预览**：打开或切换到任意 `.md` 文件时，自动在右侧编辑器栏显示预览
- **自动关闭**：切换到非 Markdown 文件时，自动关闭右侧预览窗口
- **焦点保持**：预览打开后焦点自动回到左侧的 Markdown 源文件，不影响编辑

## 使用方式

无需任何配置或命令，安装即用：

1. 打开任意 `.md` 文件 → 右侧自动弹出预览
2. 切换到其他文件 → 预览自动关闭
3. 在多个 `.md` 文件间切换 → 预览内容自动跟随更新
